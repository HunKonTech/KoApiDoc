# Contributing

This repository is public, but **external pull requests and code contributions are not accepted**.

- Report bugs and ideas in an issue (the templates ask for what helps reproduce a problem).
- Security problems: report them privately, see `SECURITY.md`.
- Modifying or redistributing the source code requires the owner's written permission (see `LICENSE`).
- External pull requests are closed automatically.

# Közreműködés

Ez a repó publikus, de **külső pull requestet és kódot nem fogadunk el**.

- Hibát vagy ötletet issue-ban jelezhetsz.
- Biztonsági hibát privát módon jelezz, lásd `SECURITY.md`.
- A forráskód módosítása és újraterjesztése csak a tulajdonos írásos engedélyével lehetséges (lásd `LICENSE`).
- A külső pull requestek automatikusan lezárásra kerülnek.
