# Supported Specifications

| | |
| --- | --- |
| Versions | Swagger 2.0, OpenAPI 3.0.x, OpenAPI 3.1.x |
| Formats | JSON and YAML (UTF-8) |
| Sources | pasted text, or an attachment of the same page |
| Attachment size | up to 2 MB |
| Themes | Confluence light and dark |

Internal references (`#/components/...`, `#/definitions/...`) work. References to other files or URLs are not loaded; they are listed in a note above the documentation. Bundle multi-file specifications into one file first.
