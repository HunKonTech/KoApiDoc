# Troubleshooting

| Message | What to do |
| --- | --- |
| No specification yet | Edit the macro; paste a spec or choose an attachment. |
| Invalid specification | Not valid JSON/YAML, `openapi`/`swagger` field missing or unsupported, or too many YAML aliases expanded. |
| The specification could not be displayed | Structure is not valid OpenAPI. Check it with a validator. |
| You do not have permission | You cannot view the attachment, or the app was not allowed to read it. Ask the page owner or an admin. |
| The attachment was not found | Deleted or moved. Choose another attachment. |
| Larger than the 2.0 MB limit | Reduce the file or show it in parts. |
| Is not a text file | Save as UTF-8 JSON or YAML. |

Still stuck? Open an issue: <https://github.com/HunKonTech/KoApiDoc/issues>
