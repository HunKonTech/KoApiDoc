# FAQ

**Is it free?** Yes, including commercial use.

**Can I modify or redistribute it?** Only with the owner's written permission. See [[License and Contributing]].

**Does it send my API spec anywhere?** No. It is processed in the reader's browser and no data leaves Atlassian.

**Can readers call my API from the page?** No, there is no "Try it out".

**Does the page update when I change the spec?** With an attachment source, yes: upload a new file version.

**Why is the macro missing in PDF export?** Confluence exports do not run app macros.

**Where do I report bugs?** GitHub Issues. Security problems: private vulnerability reporting.
