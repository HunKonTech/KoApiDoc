# Limitations

- No "Try it out": requests to your API are not sent from the page.
- External `$ref` targets are not loaded.
- Remote images are not shown; embedded `data:` images work.
- Attachments over 2 MB are rejected; use tags or split the spec.
- Confluence PDF/Word export and printing do not run app macros.
- Attachments of the same page only; one specification per macro.
