# Getting Started

## Install

A Confluence site administrator installs KoApiDoc from the Atlassian Marketplace (once it is listed) by searching for **KoApiDoc**. Installation asks for two read-only permissions, used to read attachments of the page that contains the macro.

## Add the macro

1. Edit the page.
2. Type `/` and select **KoApiDoc**.
3. Choose the source and display options, then **Save**.
4. Publish or update the page.

To change it later, edit the page, select the macro and use its edit button.

![Configuration](images/05-configuration.png)

## Update the documentation

With an attachment source, upload a new version of the same file. Readers see it the next time they open the page.
